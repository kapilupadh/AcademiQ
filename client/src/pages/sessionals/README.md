# Sessional Exams Pages

**Developer 4 Responsibility**

This directory contains pages for sessional exams (MCQ module).

## Subdirectories

- `ExamList/`: List of upcoming exams.
- `ExamInterface/`: Main exam taking interface.
- `ExamResult/`: Result display.
- `CreateExam/`: Exam creation interface.
- `QuestionBank/`: Question bank management.
