# Pages Directory

This directory contains page-level components organized by module.

## Modules

- `auth/`: Authentication pages (Login, Register).
- `dashboard/`: User dashboards (Student, Teacher, Admin).
- `assignments/`: Assignment management pages.
- `sessionals/`: Exam and sessional pages.
- `marks/`: Marks entry and viewing pages.
- `attendance/`: Attendance tracking pages.
- `admin/`: Admin setup and management pages.
- `notifications/`: Notification center pages.
