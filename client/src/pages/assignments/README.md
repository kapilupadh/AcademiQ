# Assignments Pages

**Developer 3 Responsibility**

This directory contains pages for assignment management.

## Subdirectories

- `AssignmentList/`: List of available assignments.
- `AssignmentDetails/`: Detailed view of an assignment.
- `SubmitAssignment/`: Student submission interface.
- `GradeAssignment/`: Teacher grading interface.
- `CreateAssignment/`: Teacher assignment creation interface.
