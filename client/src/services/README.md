# Services Directory

This directory contains API service modules for communicating with the backend.

## Key Files

- `apiConfig.js`: Axios instance and configuration.
- `authService.js`: API calls related to authentication.
- `assignmentService.js`: API calls for assignments.
- `examService.js`: API calls for sessional exams.
- `marksService.js`: API calls for marks management.
- `attendanceService.js`: API calls for attendance tracking.
